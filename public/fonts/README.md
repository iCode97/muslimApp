# Self-hosted fonts

Inter (300-700, variable), Amiri (400/700) and Noto Sans Arabic (400-700, variable)
as woff2 subsets (latin, latin-ext, arabic), fetched from the Google Fonts
distribution and served from this origin so that no request to Google is made.
All three are licensed under the SIL Open Font License 1.1 - see `LICENSE-OFL.txt`.
The `@font-face` rules live in `app/assets/css/main.css`.
